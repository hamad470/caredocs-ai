RAG Architecture

Indexed Sources

  • Care notes (narrative + concerns + actions)
  • Incident records (description + lessons learned)
  • Previous care plan sections (each section indexed separately)
  • Wellbeing assessments (summary + outcomes)
  • Risk assessment narratives

Chunking Strategy

  • 80-word chunks with 20-word overlap
  • Sentence-boundary aware splitting
  • Metadata: resident_id, source_type, section, date

Retrieval Safety

  • Resident isolation enforced before FAISS search
  • Cross-resident retrieval architecturally impossible
  • Every retrieval event logged to rag_audit_log
