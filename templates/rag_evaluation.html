What this page is for

When the system answers a question about a resident, it does not answer from memory. It searches that resident's own records, puts what it finds in front of the language model, and asks the model to write from those records only. That design is meant to stop the model inventing things — but a design intention is not evidence. This page is the evidence, and it is laid out so that a reader who does not work with machine learning can reach the same conclusion as one who does.

Three things have to be true for an answer to be trustworthy, and they can fail independently, so they are tested separately. Retrieval has to put the right record in front of the model. Grounding means what comes back is actually built from those records. Isolation means the records shown are only ever that resident's. Each has its own question below.

Experiment 1 — which retrieval stages earn their place

Retrieval was built in stages, and each stage was kept only if it paid for itself. Five arms were run over the same {{ exp.e1_ablation[0].n_queries }} known-item queries: a lexical index alone, a dense index alone, the two fused by reciprocal rank, then recency weighting, then diversification.

ArmMRRR@8nDCG@8ms

Fusion helped; the two stages after it did not. Hybrid fusion beat either index alone on every measure. Recency weighting and MMR diversification both scored slightly worse than plain fusion on this query set, and they are reported that way rather than quietly dropped — a negative ablation result is still a result, and the retrieval used in production is the arm that measured best.

The retrieval experiments above test the evidence. This one tests what the model does with it: each approved care plan section is regenerated twice, once with the resident's records retrieved and once without, and both are scored against the approved section as reference. ROUGE-L measures how much wording the generated text shares with the reference; it is a blunt instrument for clinical prose and the limitation is stated below rather than buried.

What these measurements cannot tell you

Grounding is tested lexically, not logically. A sentence is counted as supported when most of its content words appear in a retrieved record. That test passes a sentence which reuses the right vocabulary while asserting the opposite — "tolerated the medication well" against a record reading "did not tolerate the medication" shares almost every word. It also fails a correct paraphrase that happens to share none. The measure is used because it is inspectable: every verdict on this page can be checked by a human in a few seconds, which is not true of a second model scoring the first. An entailment-based check is the obvious next step and it is named as future work rather than claimed.

Retrieval is graded against one known-correct record per question. Recall@8 of {{ (hyb.recall_at_8 * 100) | round | int if hyb else '—' }} % means the record we had in mind was in the shortlist that often. It does not mean the other four questions in ten were answered badly — a different record may have carried the same information. The figure is therefore a floor on usefulness, not a measure of it, and reading it as an accuracy would understate the system.

ROUGE-L rewards wording, not correctness. Two clinically identical sections written in different words score poorly against each other; a fluent section with a fabricated detail scores well if the rest of the phrasing matches. It is reported because it is the standard comparison in the literature and because the with-and-without contrast is still informative, not because a ROUGE-L figure means the text is good.

The reference sections were generated by the same family of system. The approved care plan sections used as ground truth came out of this project rather than from a clinician's pen, so the generation experiment compares a model against material a model helped produce. Human expert review of a sample is the missing control and its absence is the single largest threat to the generation results.

Everything is measured on synthetic records. Real care documentation is messier: inconsistent abbreviation, missing days, handwriting transcribed badly, the same event written up three times by three people. The retriever has not been tested against any of that.

The position this page supports

Retrieval works and each stage of it has been justified by measurement. Confidentiality between residents is enforced by construction and has survived a deliberate attempt to break it. Grounding is demonstrable sentence by sentence, and the demonstration is on this page rather than in an appendix. What has not been established is that retrieval measurably improves the quality of the generated text, as opposed to its traceability — the ROUGE-L contrast is too small and too noisy to carry that claim, and the honest statement is that the question is still open with a named next experiment.
