How CUSUM works: Each resident's first 7 days of MAR records set a personal baseline (mean μ and standard deviation σ). The CUSUM statistic accumulates downward deviations: C = max(0, C + (μ − xᵢ)/σ − k) where k = 0.5 (allowance). When C reaches h = 4.0, an alert fires and C resets. This detects sustained drops below an individual's own baseline — more sensitive than a fixed percentage threshold.
